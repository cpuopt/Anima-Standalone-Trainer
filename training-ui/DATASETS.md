# 数据集导入、预览与局域网访问

## 启动和入口

需要 Node.js 20.19+ 或 22.12+（推荐当前受支持的 LTS），在 `training-ui` 下执行：

```sh
npm ci
npm run build
npm start
```

选择任务 → **数据集** → 子集中的 **导入数据集** 或 **浏览 / 预览**。
首次升级需重启 Node 服务；仅刷新浏览器不会加载新的后端路由。
ZIP / 7z 使用随 npm 依赖提供的 7-Zip，不需要额外安装系统 7-Zip。
缩略图使用 sharp；如果安装时禁用了可选依赖，请恢复后重新安装。

## 三种导入方式

1. **已有服务器目录**：填写绝对路径，点击「使用此目录」。不复制、不改写源文件。同机运行时这就是本地磁盘目录；其他电脑访问时仍是训练机器的目录。
2. **文件 / 文件夹上传**：通过按钮选择或拖入图片和同名 TXT。保留文件夹层级；界面会报告被忽略的非数据文件。
3. **ZIP / 7z**：一次只选一个压缩包，点击「上传并检查」。后台解压后显示图片数、TXT 数、缺 Caption、孤立 TXT、体积和含图片的目录。

检查完成后点击「确认导入并绑定」。每个直接包含图片的目录会绑定为一个独立子集，继承当前子集参数，避免训练器不递归读图而漏掉嵌套目录。随后**保存任务配置**。仅绑定目录不会改动其他 Dataset 的设置。

文件按**同目录、同文件名主干、区分大小写**配对：`人物/01.png` 对应 `人物/01.txt`。导入检查默认按 `.txt` 统计；浏览已存在目录时按 Dataset 的 Caption 扩展名配对，但首版文本预览仅开放 TXT。
图片格式兼容性仍由选用的训练后端决定；导入成功不表示每种模型都支持该图片格式。

### 限制与失败处理

| 项目 | 默认限制 |
| --- | --- |
| 单文件（包括压缩包） | 1 GiB |
| 单次上传合计 | 8 GiB |
| 解压后合计 | 16 GiB |
| 压缩包条目 / 目录扫描条目 | 10000 |
| 目录层级 | 32 |
| 单个 TXT 预览 | 1 MiB |
| 解压准备阶段 | 最长 30 分钟 |

- 不支持加密、分卷、嵌套压缩包、符号链接、硬链接、设备文件和路径穿越。
- Windows 设备名、ADS、大小写冲突和重复路径会被拒绝；不自动覆盖文件。
- 图片支持 PNG、JPG/JPEG、WebP、BMP、AVIF、JXL。浏览器或缩略图解码器不支持某格式时显示明确提示，不更改原文件。
- 上传失败后可重试，会使用新的暂存会话；首版不是断点续传。
- 关闭窗口会取消上传 / 解压并清理暂存。原子发布期间不可关闭，避免将已导入误报成失败。
- 7z 固实压缩包采用逐文件安全流式读取，文件很多时会比直接解压慢；可先在本机解压后绑定目录，或使用 ZIP。
- 任何任务训练 / 缓存准备运行期间禁止新导入；已有数据可只读预览。

## 预览

- 当前目录图片按页展示，每页 60 张，支持文件名搜索、仅缺 Caption、子目录导航。
- 点击图片同时展示原图、尺寸和同名 TXT；切换「TXT 文件」可查看孤立 TXT。
- 内容只作为纯文本显示，不执行 HTML。首版不编辑 Caption、不删除源数据。
- 缩略图按路径、修改时间和大小缓存；最多 128 项，同时最多解码 2 张图片。刷新可重新读取外部改动。

## 局域网访问与权限

### 共享访问码

在训练机器通过 `localhost`、`127.0.0.1` 或 `::1` 打开 UI，进入 **全局设置 → 局域网访问**，点击「显示访问码」。访问码默认隐藏，不会写入 URL。

其他电脑通过训练机器的局域网 IP 和服务端口访问，首次会进入登录页。输入共享访问码后可使用训练 UI、API、样例和 TensorBoard；WebSocket 也必须通过认证。**持有码者等同可信训练管理员，不是独立账号或多租户隔离。**

- 会话 Cookie 为 HttpOnly、SameSite=Strict，固定有效期 12 小时。
- 重启服务使现有会话失效，但保留共享访问码；本机重置访问码会立即断开远程实时连接、使旧会话失效，不停止训练。
- 同一来源 IP 在 15 分钟内 5 次错误登录后暂时限流。
- 会话过期不会清除浏览器内尚未保存的草稿，按提示在新标签页登录后返回继续。
- 环境安装、访问码管理、目录授权仍只允许训练机器的 localhost 界面操作。
- 旧界面和原本无需认证的远程脚本同样受保护。程序客户端需先同源登录、携带会话 Cookie，写请求额外携带与访问地址一致的 `Origin`。

**仅用于可信局域网，不要直接暴露到公网。** HTTP 不加密访问码、数据或会话。通过 TLS 反向代理使用时：

1. 设置 `ANIMA_UI_SECURE_COOKIES=1`，确保浏览器只通过 HTTPS 使用会话。
2. 原样保留外部 `Host`、`Origin` 和 WebSocket 升级头；不要将所有外部 Host 改成 localhost，否则会破坏本机免输边界。
3. 后端网络端口仅允许代理及可信设备访问；不需要启用 Express `trust proxy`，程序不信任任意 `X-Forwarded-*` 作为本机身份。

### 目录授权

- 上传到管理目录的数据集自动可预览。
- 其他服务器目录需先在本机 **全局设置 → 局域网访问 → 允许远程预览的服务器目录** 中授权。
- 授权包括全部子目录；不要授权磁盘根目录或含密钥、私密资料的父目录。
- 撤销后，已经打开的远程预览令牌也会被拒绝；已加载到客户端的内容无法收回。
- 文件访问必须处于授权边界内，链接不能用来逃出根目录。
- 这些授权约束的是新增数据集文件接口。共享访问码用户仍拥有其他训练管理权限，不能用目录授权把不可信用户隔离成受限租户。

## 保存位置与清理

以下路径均相对项目根目录，已被 Git 忽略，不通过静态目录发布：

| 路径 | 用途 |
| --- | --- |
| `training-ui/datasets/dataset-<UUID>/` | 导入成功的原始图片 / TXT |
| `training-ui/datasets/.staging/import-*/` | 上传及解压临时文件 |
| `training-ui/datasets/.authorized-roots.json` | 由本机授予的目录列表 |
| `.runtime/ui-access-code` | 持久化访问码，应限制为当前系统用户可读 |

闲置导入会话 1 小时过期；服务首次初始化数据集存储时，只清理超过 24 小时的、名称匹配 `import-*` 的生成暂存目录，不清理已发布的数据集或其他用户目录。

删除任务 / 删除配置中的子集**不会删除已上传数据**。清理已发布数据时，先停止相关训练、确认没有其他任务引用，再手动备份或移动相应 `dataset-<UUID>` 目录。不要在训练期间清理。

## 测试与上线检查

```sh
# training-ui 下
npm test
npm --prefix frontend test
npm --prefix frontend run build
```

自动化覆盖：真实 ZIP / 7z、中文路径、目录和 TXT 配对、越界 / 链接 / 重名 / 超限 / 加密 / 损坏输入、取消清理、遗留暂存清理、训练锁、图片 / TXT HTTP 预览、会话及登录限速、静态 / TensorBoard / WebSocket 认证、目录授权和撤销、前端上传进度、重试和任务切换。

双机验收清单（需要实际局域网设备）：

1. 本机免输访问，第二台机器访问相同服务时出现登录页。
2. 远程登录后实时连接正常，上传 ZIP / 7z 并确认导入，保存配置。
3. 图片与 TXT 能显示，缺 Caption 和孤立 TXT 计数正确。
4. 远程不能绑定未授权目录；本机授权后可预览，撤销后立即拒绝。
5. 本机重置访问码后远程连接关闭，旧会话无法访问 API / 图片。
6. 训练期间只读预览可用，导入与绑定入口不可修改数据配置。

本次浏览器已验证同机 7z 上传 → 两目录绑定 → 保存 → 图片和中文 TXT 联动；认证和 LAN Host 行为由自动化 HTTP / WebSocket 测试覆盖。真实第二台设备、操作系统防火墙及实际 TLS 代理链路需在部署环境验收。
