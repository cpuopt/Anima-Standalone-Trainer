# 训练产出

重启 UI 服务后，选择任务 → **训练产出**。

## 模型文件

- 列出任务 `output/` 中实际存在的 `.safetensors`、`.ckpt`、`.pt`、`.pth`、`.bin` 权重，包含每轮、按步保存和最终模型；跳过 TensorBoard 日志和 `*-state` 恢复状态目录。
- 表格包含文件名、相对路径、Epoch / Step、大小和修改时间，支持搜索、分页及单文件下载。
- `name-000003`、`name-step00000100` 等轮次标签从项目训练器的文件命名推断。未明确标注轮次的文件不会被编造出轮次；真实训练信息可通过 Safetensors 元数据确认。
- 「预览信息」仅读取最多 8 MiB 的 Safetensors 文件头，显示元数据、Tensor 总数及前 100 项结构，不加载权重到 GPU，也不反序列化 PyTorch Pickle。其他权重格式只显示基本文件信息，可直接下载。

如需**每轮**保留模型，在训练页面将 `Save Every N Epochs` 设为 `1`，并检查是否存在会删除旧文件的保留策略。本标签页不改变训练配置，也不能恢复已经删除或从未保存的轮次。分片权重需要下载所有相关分片，首版不提供整目录打包。

## Sample 图片

- 图片区包括任务 `output/` 下的训练 Sample，以及 `samples/` 下的独立生成图片，可按来源筛选。
- 支持缩略图、原图预览、文件大小 / 修改时间和原图下载。
- 没有训练 Sample 时，需要在「提示词与生成」配置采样提示词，并启用按轮次或步数采样。
- 不支持的图片解码格式会显示提示，仍可下载原文件。

## 刷新、下载与安全

- 当前标签页显示时默认每 10 秒刷新；可以关闭自动刷新或手动刷新。隐藏标签页不会持续扫描产出。
- 空文件或最近 2 秒内变化的文件暂不可下载。下载 / 预览会再次校验文件大小与修改时间，列表过期时返回错误并要求刷新。
- **短暂稳定不代表大文件一定保存完成。** 模型写入期间可能出现停顿，尤其是慢盘 / 网络盘；请以训练日志的保存完成提示为准。下载期间不要覆盖或删除正在读取的文件。
- 文件通过流式响应发送，不将整个模型读入 Node 内存；首版不提供批量 ZIP、断点续传或校验和生成。
- 所有新接口复用全站访问码会话，仅读取当前任务 `output/` 与 `samples/` 下允许的文件类型；拒绝路径穿越、符号链接和目录越界。不提供产出删除功能。
- 每次最多扫描 20000 个目录条目，最多递归 16 层；达到上限会在页面明确提示列表不完整，每页最多显示 40 项。

接口：

- `GET /api/jobs/:name/artifacts?kind=models|samples&query=...&source=all|training|generation&page=0`
- `GET /api/jobs/:name/artifacts/preview?path=...&version=...`
- `GET /api/jobs/:name/artifacts/file?path=...&version=...&download=true`

`path` 为接口返回的任务内相对路径；`version` 是文件大小 / 修改时间标识，不是加密哈希或完整性证明。
