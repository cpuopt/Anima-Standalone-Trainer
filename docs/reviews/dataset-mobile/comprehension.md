# Comprehension — BRAINSTORM

Status: completed. Seven Majors. Core lens: UX/cognitive burden. These are proposed design requirements, not implementation authorization or scope expansion.

## Findings

1. **U1 — Major: Keyboard-open phone inspection is unproven.** Evidence: brief Analysis; notes Per-image editor/Dataset overview. Long tags/prose can push image/navigation away; zoom/text selection/swipes compete. Proposed: review a representative long-caption phone journey with keyboard open, preserving image/folder/save/navigation context and overview position. No layout is selected.
2. **U2 — Major: Import needs an understandable independence promise.** Evidence: brief Overview/Analysis; notes ownership/entry workflow. Selection, enumeration, copy and verification differ. Proposed: visible stages, cancellation/resume/reauthorization choices, incremental space explanation and distinct verified completion before source removal.
3. **U3 — Major: Saved and undoable are separate promises.** Evidence: brief Analysis/Key Decisions; notes ownership/Main objections. Users cannot yet tell whether navigation/closing is safe or whether autosaved mistakes are recoverable. Proposed: define saved acknowledgement and navigation with pending data; decide undo scope/restart behavior separately. Unlimited history is not confirmed; save/translation/export errors must remain distinct.
4. **U4 — Major: Correction must precede confident classification.** Evidence: brief Analysis; notes rule examples/editor/formatting. Users need to recognize and repair wrong splits without retyping. Proposed: compare raw text with fields, deliberate boundary correction, visible uncertainty, explicit no-vlm treatment for unconfirmed parses.
5. **U5 — Major: Translations can be mistaken for training content.** Evidence: brief Overview; notes direction/editor/translation quality. Bilingual chips/view switching can obscure exported values. Proposed: consistently identify editable source versus preview, distinguish unavailable translation from empty source and preserve manual editing during translation failure. Languages/providers/downloads/dictionaries remain open.
6. **U6 — Major: View/filter/move/run scope is cognitively expensive.** Evidence: brief Analysis; notes subsets/conflict checkpoint. An accurate plan can still surprise when its evaluation scope is unclear. Proposed: name scope/count/folder context and matched conditions/destinations; determine whether individual resolution handles expected conflicts before adding group controls. Retain explicit execution/manual conflicts.
7. **U7 — Major: Partial exports need unmistakable outcomes.** Evidence: brief Analysis/Goals; notes ownership/export. Incomplete directories can look usable; generic failures omit destination, revision and retry behavior. Proposed: distinct successful/cancelled/failed outcomes, identifiable partial output, collisions and predictable recovery. Decide whether export restores project metadata/history; do not imply training TXT output is a full project backup.
