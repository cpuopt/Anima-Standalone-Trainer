# TensorBoard 页布局探索

用户要求：重新设计 TensorBoard tab，充分利用左侧下方空白。

范围：本轮交付三个可运行设计原型、六候选总览。用户选定前不修改应用实现。
共同画布：1600×1000 桌面，375×812 窄屏验证。保留 Training Studio 任务侧栏、顶部任务工具栏与 tab。

已确认根因：TensorBoardPanel.vue 使用 page-columns；style.css 在1550px以上将其等分为两列。左侧只容纳服务操作和简短说明，右侧75vh iframe，导致左下长空白且图表过窄。

共同内容：服务启动/停止/刷新、新窗口、当前任务、架构、训练状态、日志相对位置、无数据与加载失败的排障说明。真实服务仍走现有 status/launch/stop API，图表继续由原生 TensorBoard iframe 承载。
演示：style_neco 与所有曲线均为明确标记的原型内容，不代表实时训练结果。复制的是任务相对路径，不冒充服务器绝对路径。原型新窗口打开自身以供预览；正式版保持实际服务URL。服务停止与训练停止分离。

Form 五问：叙事角色是训练观察工具；观众是熟悉训练的桌面用户；温度沿用现有深/浅主题；容量以曲线优先、操作其次；母题是服务控制与训练曲线的主从关系。A来自状态和排障的纵向关联，B来自多曲线横向比较需求，C来自观察/排障两种工作模式。

假设：用户所说左下空白指 tab 内左控制列，而非全局任务导航。全局导航不改。不给外层页面增加重复的原生图表设置，也不新建指标读取后端。
