# 六个候选

共同主角：训练曲线及其服务状态，不使用摄影或与任务无关的视觉素材。

A / 侧栏工作台。设计师思路来源：Dieter Rams 的工具秩序，将持续可见的信息按操作、任务、路径、排障组织。280px辅助列加弹性图表列。胆量用于打破现有1:1等分。Form来自训练观察时服务状态与任务上下文必须同时可见。推荐主版。

B / 全宽画布。设计师思路来源：Bret Victor 的直接观察，将最重要的可观察内容连续展开。服务操作横条、全宽曲线、下方任务/路径/排障带；浅色使用项目现成主题。胆量用于取消左控制列。Form来自曲线比较的横向空间。主版。

C / 折叠辅助栏。现实参照：Grafana观察界面的辅助区与工具条层级，文档截图 refs/grafana.jpg；已亲眼查看。借用窄工具区、主画布、按需收起的关系；不声称看到完整Grafana dashboard截图。230px辅助栏，原生浅色曲线保持独立。胆量用于专注模式一键铺满。Form来自排障和观察两种模式。主版。

D / 概览矩阵。现实参照：TensorBoard官方入门文档的多曲线展示；https://www.tensorflow.org/tensorboard/get_started 。官方页面截图在refs/tensorboard-doc.png。三块任务信息横排，图表在下方。备选，顶部信息占据更多高度。

E / 右侧检查器。轮盘记录秒数24：网页候选为5号Pure-CSS Art。查看总览后对训练工具适配度低，顺延至17号功能主义网格（内容适配降级，保留细线与功能分区，不做装饰插画）。图表在左、检查器在右。备选，操作视线更远。

F / 页边注释。轮盘24 % 12 + 1 = 东亚1号吕敬人书籍设计。已打开01-lu-jingren-bookcraft.jpg。只迁移正文/旁注层级与细线分区，维持本项目系统字体和深色主题，非书籍外观复刻。备选；纯排版层级较安静，空间利用弱于A。

六格见design-demos/thumbs.html。A/B/C分别以持续辅助侧栏、全宽画布、可折叠辅助区形成结构差异。
