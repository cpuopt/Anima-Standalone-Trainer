# 现有视觉资产

Training Studio 标记与名称来源于 frontend/src/app/App.vue；颜色与字体来自 frontend/src/style.css。原型延续 A 文字标记，不引入其他产品的装饰 logo。

深色背景 #10151f、面板 #171e2b、边界 #2b374c、文字 #e0e7f2、强调 #86aafa。B使用项目已有浅色主题。C使用中性炭黑区分辅助信息层级。系统字体 Segoe UI / Microsoft YaHei；路径使用 Consolas。

TensorBoard使用官方文档核实的原生界面作为内容参照。文字产品名称正常呈现；原型不手绘品牌图形、不用TensorFlow图标冒充TensorBoard。图表与曲线是程序化绘制且明确标记为演示，正式实现不重绘原生iframe。
