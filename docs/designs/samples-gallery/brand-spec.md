# 本项目设计上下文

资产来源：`training-ui/frontend/src/style.css`、`features/samples/SamplesPanel.vue` 与本地 `@style_neco` 的样例 PNG。

现有产品没有发现独立 Logo 图档，原型保留文字 ANIMA，不虚构外部品牌徽标。参考品牌不在原型界面出现，不需要把其 Logo 当成本产品资产。

现有样式：背景 #10151f，面板 #171e2b，边界 #2b374c，文本 #e0e7f2，弱文本 #94a3bb，强调色 #86aafa；浅色背景 #f5f7fa，文本 #202b40，强调色 #326cd4。使用 Segoe UI / Microsoft YaHei 系统字体。A沿用深蓝，B从图像黄灰色取低饱和琥珀，C沿用浅色与蓝色。

素材已检视，采用四张着装角色研究图，包含真实横向与纵向画幅，内嵌为 JPEG 预览，不修改原文件。下载功能导出原型内嵌预览并加 prototype 后缀。
