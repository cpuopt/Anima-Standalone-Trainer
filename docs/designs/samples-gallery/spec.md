# 样例页原型共同规格

用户需求：为本项目样例 tab 重新设计原型；图库尽可能紧凑；详情图片独立滚轮缩放；适应横屏、竖屏、横图、竖图。

交付范围：独立 HTML 交互原型，方向选择后再做选定方向的细化。当前不改 Vue 生产页面。

现有能力：按 Prompt 分组、筛选、拖动排序、多选、框选、删除、下载、方向键切图、参数查看。三个方向保留核心浏览入口；原型实现分组筛选、搜索、排序、多选、详情、下载和缩放。不模拟真实文件删除或后台生成。

尺寸：桌面 1440×900；手机竖屏 390×844（另验375×812）；手机横屏844×390；平板竖屏768×1024。三方向使用相同素材和36条演示记录。

图库：压缩卡片留白；短标签覆盖图底；原始文件名进详情；每行/每组清楚标出 Prompt 与轮次；可调缩略图大小。演示记录重复本地素材用于检验密度，不表示真实生成数。

详情：初始完整适应视口、不裁图；滚轮围绕指针缩放；拖动平移；双击/按钮复位；1:1；上一张/下一张；可折叠参数；参数区单独滚动；Esc退出并恢复焦点。支持触屏拖动与双指缩放。切图和屏幕改变后重新适应。

排版策略：横屏左右分栏；竖屏画布在上、参数在下；优先画布，参数可收起。主界面和详情均不出现横向页面溢出。

假设：沿用本项目现有蓝色语义与中文系统字体；以桌面高频训练样例筛查为主，兼容手机查看。所有数值和提示词明确标为演示，未宣称已连接元数据接口。

Form五问：角色是训练结果的密集浏览器；观看距离为桌面近距/手机手持；温度是安静的工具界面；容量优先图片而非卡片说明；视觉母题来自 Prompt 与 Epoch 两个训练坐标。
