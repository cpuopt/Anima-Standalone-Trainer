# 六个候选

1. **A 原比例密铺（完整版）**。设计师思路：Dieter Rams 的内容优先与低操作负担。借用既有项目的深蓝语义色、5px图间距和克制工具条；素材是四张真实本地样例。骨架：三列Prompt分组，每组内部两列原比例密铺。胆量只用在取消卡片正文，标签进图底。Form来自训练样例的原比例与Prompt分组；细节为右侧检查器。
2. **B 紧凑联系表（完整版）**。现实参照：Eagle实际素材库界面，官方截图见refs/eagle.jpg；darktable仅作缩放/导航交互参考。借用窄分组栏、满宽等格缩略图和可收起检查器。主角为真实图片；骨架：左分组/右连续联系表，详情为全画布与可选悬浮参数、底部胶片带。胆量用于让整面图片占据主视野；Form来自连续筛查大量轮次的动作。
3. **C 轮次对照矩阵（完整版）**。设计师思路：Josef Müller-Brockmann 的网格秩序与共同基线；借用行列对齐和中性色细边。主角为同一Prompt跨Epoch的真实素材演示；骨架：Epoch为行、Prompt为列，同格种子并排。详情为缩略导航/画布/检查器三栏。胆量是把分组转为比较坐标；Form来自训练过程的两个天然维度。
4. **D 图像优先单流（备选）**。现实参照：Eagle官方素材库，截图同上。规则：去分组列，用图底标签和满宽瀑布流，分组交给过滤器。主角是完整横竖图；骨架：全宽连续原比例流。胆量花在压到3px图间距。Form来自一眼找出异常图的动作。
5. **E 黑白索引墙（备选）**。轮盘：开工采样秒数38，网页20项，38%20+1=19；已查看`web/19-swiss-monochrome.jpg`。规则：黑白细线、等宽轮次标签；不搬样张的大标题，以紧密等格索引适配工具。骨架：极窄标题区+黑白联系表。主角是真图，唯一强调为选中边框。Form来自高密度索引。
6. **F 细线分册（备选）**。轮盘：秒数38，east12项，38%12+1=3；已查看`east/03-republic-book-jacket.jpg`。迁移低饱和灰纸与分隔线，不复制书脊、装饰或竖排。骨架：横向轮次分节、每节连续一条图片。主角是真图，胆量为单色轻底与轮次索引。只迁移信息分册规则，弱化原样张的书封道具感。Form来自分轮次归档。

挑选A/B/C：原比例完整浏览、等格高密筛查、训练坐标对照各有不同骨架；六格缩略页保留D/E/F供进一步选择。三版都有独立可操作详情，不以换色充当结构差异。
