# 本项目资产与样式

基准源码：`frontend/src/features/console/ConsolePanel.vue`、`memory-view.ts`、`terminal.ts`、`frontend/src/style.css`、`lib/hardware.js`、`stores/editor.ts`。

本产品在源码中的文字标识为Training Studio，覆盖Anima / Krea 2 / MOSS。原型不添加第三方品牌Logo，不把参考作品品牌表现为本产品的集成。

深色：背景#10151f，面板#171e2b，边界#2b374c，文字#e0e7f2，强调#86aafa；浅色：背景#f5f7fa，文字#202b40，强调#326cd4。字体Segoe UI / Microsoft YaHei，日志Consolas。A延续深蓝，B用现有浅色主题，C用低色温炭黑与清晰的蓝色选择状态。

主角素材是运行日志与模型/GPU存储分布，通过真实字段构造的明确演示数据。无需摄影、生成人物或装饰素材。参考截图单独留存在refs，不放第三方品牌到产品UI。
