# 六个设计候选

1. **A 横向仪表带 / 主版**。设计师思路：Dieter Rams的信息优先级与动作经济。借用已有深蓝主题，将短硬件快照压成横带，长日志得到全宽，模型明细移到可折叠底栏。主角是日志与存储分布，不是大数字。骨架：资源横带 / 全宽日志 / 节点明细。胆量用于取消永久左栏；Form来自硬件快照短、日志持续增长的内容差异。
2. **B 窄栏诊断 / 主版**。现实参照：Grafana官方Explore日志，refs/grafana.jpg。借用窄工具区和大内容区、筛选与内容紧邻；不复制查询语言或品牌。现有浅色主题，日志区域保留深色以稳定阅读。骨架：左320px监控+模型位置+关键节点，右侧弹性日志。主角为GPU分配条与节点表。胆量是把当前硬件列收窄；Form来自模型清单适合窄表、日志需要长行。
3. **C 日志专注 / 主版**。设计师思路：Jef Raskin对主任务的持续可见与按需工具。借用任务聚焦而非某件作品的外观。骨架：几乎全屏日志 / 底部硬件状态带 / 右侧诊断抽屉。主角是日志原文，资源状态常驻可见。胆量为硬件明细按需叠置；Form来自排障时先找日志、再确认显存的操作路径。
4. **D 上下双工作区 / 备选**。现实参照：W&B运行日志官方文档，refs/wandb.jpg；实际视觉根据截图可见界面提炼。上半日志、下半GPU与模型位置；多GPU为横向表格。主角为两种记录的共同时间节点。胆量是上下等权，而非左右；Form来自日志/资源同样重要的重度监控场景。
5. **E 触感状态台 / 备选**。轮盘采样S=43，web 20项取第4项Friendly Candy，已查看`web/04-friendly-candy.jpg`。迁移明确的按下态和高可辨识状态按钮，不使用吉祥物、超大字号或营销模块。骨架：顶部紧凑状态格，下方日志。主角仍为真实字段，唯一大胆处为实体按钮感。Form来自频繁切换GPU与日志级别。
6. **F 分层资源图 / 备选**。同一S=43，east12项取第8项杉浦信息曼荼罗，已查看`east/08-sugiura-info-mandala.jpg`。借用层级关系与连接标注，去掉装饰性的天文盘；以GPU/模型/CPU三个同心层级展示卸载位置。骨架：小型分层资源图+日志，明细可展开。主角为模型存储映射；大胆处只在资源关系图。Form来自同一模型跨CPU/CUDA的分布。此版只作探索，不伪装为已存在的数据功能。

优先A/B/C：三种空间策略不同；不以换颜色充当方向差异。三版共用完全相同的字段、日志与演示状态。
