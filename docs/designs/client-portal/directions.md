## 候选 1（入选完整版 → `dir-2.html`）· 最佳设计师 A：极白美术馆展厅
- **逻辑与来源**：最佳设计师 — 原研哉（Kenya Hara）白盒美术馆与器物策展哲学。
- **借的是什么**：极浅暖纸白底（`#F9F8F6`）、极细 1px 灰线、超大呼吸感留白、作品自带全部色彩、状态点缀仅用克制墨绿（`#1E6B52`）与浅暖灰。
- **主角素材**：6 张定制水彩/赛璐璐 LoRA 实拍预览图（高彩度画作成为页面唯一视觉重心）。
- **骨架**：无侧栏单轴流 — 极简展签眉栏（项目名 + 阶段状态 + 极轻量视图切换）→ 全幅不对称瀑布流展墙 → 授权后优雅浮现的「交付档案区 / 抽拉式交付清单」。
- **胆量花在哪**：彻底去掉传统后台侧栏与厚重卡片边框，把客户验收站做成一座私人线上画册与展厅。
- **form 来自内容的哪里**：定制画风 LoRA 的验收核心是画作本身的气质与笔触，UI 退隐才能让甲方把全部注意力放在画面表现上。

## 候选 2（入选完整版 → `dir-1.html`）· 最佳设计师 B：精密暗房审片台
- **逻辑与来源**：最佳设计师 — Dieter Rams 功能主义 × 专业校色暗房工作台。
- **借的是什么**：中性无色偏炭黑底（`#0E1013`）、1px 精密结构线、等宽数字索引（`E12 · 1024×1360 · BF16`）、硬件保险灯式权限状态（琥珀=未授权预览 / 翡翠绿=已授权交付）、紧凑高密度检片控件。
- **主角素材**：6 张预览图置身纯中性暗房画布，高光、笔触与暗部过渡零色偏呈现。
- **骨架**：左 248px 固定「审片与授权控制栏」（项目档案 + Prompt 分组筛选 + 权限解锁状态矩阵）+ 右全幅自适应审片工作区（顶部工具条 + 预览画廊 / 模型库 / 参数表 / 数据集切换）。
- **胆量花在哪**：把客户交付台做成美术总监专用的专业暗房检片仪，快捷键、1:1 放大镜与权限保险开关一丝不苟。
- **form 来自内容的哪里**：插画与游戏美术甲方看 LoRA 样图最在意色准、线条细节与不同 Epoch 对比，无偏色暗房环境直接服务于真实审片动作。

## 候选 3（入选完整版 → `dir-3.html`）· 现实参照 A：分屏交付工作舱
- **逻辑与来源**：现实参照 — Frame.io（专业视觉资产客户审片与交付平台）。
- **借的是什么**：清爽高对比冷灰工具面（`#F4F5F7`）+ 纯白内容画布 + 深靛蓝主动作色（`#1E3A8A`）、顶部阶段进度条（预览验收 → 付款授权 → 资产提货）、主画廊与右侧常驻交付舱同屏联动。
- **主角素材**：6 张预览图按 Prompt 分组网格排列，悬停浮现轮次标签与快速灯箱/下载按钮。
- **骨架**：顶部阶段导航与搜索工具栏 + 左主右辅双栏（左：分 Prompt 组预览画廊；右：340px 常驻交付资产舱，未付费时展示锁定态与交付说明，授权后原地变为一键下载中心）。
- **胆量花在哪**：打破「看图一页、下载另一页」的割裂，一屏同框完成看样验收与付费提货。
- **form 来自内容的哪里**：业务本质是「先看样图确认、后付款按项提货」的商业履约流程，双栏同屏让权限变化与交付物清单时刻可见。
