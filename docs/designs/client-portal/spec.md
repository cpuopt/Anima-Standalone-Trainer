# Anima Client Portal · 客户预览与成果交付系统设计 Spec

## 1. 项目定位
独立于现有 3000 端口训练系统的**客户侧只读预览与交付 Web UI**（平行独立程序，仅向客户暴露经训练师筛选/授权的成果，彻底隔离训练后端与未授权资产）。

## 2. 受众与核心使用场景
- **受众**：委托定制 LoRA / 画风 / 角色模型训练的甲方客户（插画师、游戏美术总监、内容工作室、独立创作者）。
- **核心两阶段工作流**：
  1. **阶段一 · 成果预览期（未付费 / 验收前）**：
     - 绝对禁止暴露或下载任何模型权重文件（`.safetensors` 等）。
     - 训练参数、数据集配置等完全不可见。
     - 客户仅能浏览训练师在后台勾选同步或手动上传的「客户可见预览图」。
     - 看图体验对标训练系统「样例」页：支持 Prompt 分组筛选、文件名/轮次搜索、排序、缩略图密度调节、多选批量下载预览图，以及专业级灯箱看图器（滚轮缩放、拖拽平移、双击适应、1:1 原图、键盘导航、单张下载）。
  2. **阶段二 · 权限交付期（已付费 / 按项授权）**：
     - 训练师在后台为该客户逐项配置权限，客户端 UI 依据三项独立权限动态解锁：
       - **可见训练参数**：只读查看核心训练配置（基础架构、网络类型/Rank/Alpha、学习率与调度器、训练轮次与步数、分辨率与精度、采样说明），支持复制配置摘要或导出 `.toml`。
       - **下载数据集**：查看数据集概况（图像张数、标注完整度、分辨率分布、归档大小与 SHA-256），一键下载数据集打包文件。
       - **下载指定 LoRA 模型**：仅展示训练师指定的权重版本（如 `Epoch 16 终版`、`Epoch 12 柔和版`），显示体积、精度、SHA-256、Safetensors 元数据预览及直链下载。

## 3. 原型演示假设（Assumptions）
- 示例委托项目：`星尘水彩 · Cel-Ink Atelier v2`（Anima 架构 LoRA 定制委托，客户标识 `Atelier K · #ORD-2026-1121`）。
- 预览图共 6 张，分属 `Prompt 1 · 人物立绘`（E12 / E16）、`Prompt 2 · 场景光影`（E12 / E16）、`Prompt 3 · 器物细节`（E16）及 `训练师精选上传`（Showcase）。
- 为便于训练师评审两种阶段与 8 种权限组合，所有原型内置一个紧凑的「权限状态模拟器（Demo Switcher）」，支持一键切换 `未付费预览`、`仅交付模型`、`全权限交付` 以及单独勾选三项权限。

## 4. 输出格式与硬性规格
- **交付形态**：单文件独立交互 HTML 原型（资源内嵌或相对路径清晰可运行，最终交付版单文件内嵌）。
- **视口规格**：桌面端 `1440×900` 为主，完整响应式适配移动端 `375×812`。
- **可读性底线**：正文 ≥14px，辅助标签 ≥12px，正文对比度 ≥4.5:1，所有交互控件真可点击、无控制台报错。
